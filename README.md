One line, 200 characters, roasting your own AI agent. Free entry, $5 over the top three places, 24 hours open, judged pairwise on funniness, freshness and tight wording.

The entry is one original roast of my own AI agent (Jett): a single line, funny and playful, never hateful. The program writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write elsewhere, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py`.
